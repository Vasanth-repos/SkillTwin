# Changelog — SkillTwin

## [1.1.0-ENTERPRISE] - 2026-08-20

### Added
- **Multi-Role "What-If" Benchmark Simulator:** Added side-by-side readiness benchmarking across all target roles (Backend, Full-Stack, DevOps, Data Analyst) with 1-click active target switching.
- **Verified Digital Skill Credential Export:** Generates printable/shareable verified credential cards with unique verification IDs, skill competencies checklist, QR simulation, and clipboard sharing.
- **Interactive Repository Artifact Explorer:** In-modal file tree inspector showing discovered repo files (`Dockerfile`, `docker-compose.yml`, `tests/`) and matching rubric rules.
- **College Admin Curriculum Intervention Generator:** Department chair workshop syllabus generator addressing the #1 institutional cohort deficit.
- **1-Click Cohort Telemetry CSV Export:** Placement director CSV export for institutional reporting and recruiter sharing.
- **Student Milestone Badges:** Achievement showcase highlighting algorithmic, containerization, database, and project portfolio milestones.

## [1.0.0-MVP] - 2026-08-20

### Added
- **Core Architecture & Scaffolding:** Express backend, Prisma ORM, and React Vite frontend.
- **Antigravity Framework:** `.agents/` rules, skills, hackathon-judge agent, and 6 workflow slash commands.
- **Deterministic Skill Engine:** Heuristic algorithm for student profile scoring, target role gap prioritization (`gap × importance × relevance`), and career readiness score calculation.
- **Rubric Evaluator:** Automated checklist evaluator for GitHub repositories.
- **Seed Dataset:** 4 Target Roles, 16 hands-on missions, 4 demo personas.
- **Student & Admin Dashboards:** Interactive gauges, Recharts radar/bars, institutional heatmap, student roster.
